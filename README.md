# Planetmint Interfacer

Deployment utilities for Planetmint in the Interfacer project.

The [devops](devops/) directory contains Ansible playbooks for installing, configuring, starting, stopping, and removing Planetmint nodes, together with supporting scripts and templates. Review the configuration and target hosts before running deployment commands.
